# The Spanish Experiment

A public learning experiment built around Guillermo F. Hall Avilés’ public-domain course *Poco a Poco: An Elementary Direct Method for Learning Spanish*.

The site follows a simple rhythm: read, copy by hand, answer aloud, listen back, speak with Spanish speakers, and record honest reflections.

## Current state

- Spanish red, gold, parchment and black visual identity
- Home, schedule, materials and milestones
- Course page
- Lesson 1 aligned to *Poco a Poco*, Parte Primera, Lección Primera

## Source text

Hall Avilés, Guillermo F. *Poco a Poco*. World Book Company, 1922. Public-domain scan: https://archive.org/details/pocopocoelementa00hallrich
